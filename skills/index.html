Skills & web

Teach it once, reuse it.

Teach your agents how your team works, once.

A skill is a short set of instructions for a specific job, like a release checklist or a design guide. Agents see what’s available and load a skill only when the task calls for it, so you can keep dozens without slowing them down.

Research built in.

Deep research, web search and page reading come built in, so agents check current docs instead of guessing.

Shared with the team.

Keep skills in the project to share them with everyone, or in your own folder to use them in every project.

Write it down once, and every agent knows it.
