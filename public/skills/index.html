Skills

Teach it once. It follows every time.

A skill is a folder of instructions for one kind of task.

KodaCode reads skills from your project, your global folder and the folder that other agent tools share. The agent sees the name and description of each skill, and reads the whole skill when a task needs it. Pick a skill yourself and it goes with your next message, so the agent follows it from the first step.

Install from a link, scanned first.

Paste a SKILL.md link, a GitHub folder or an archive. Before it installs, KodaCode checks every file for hidden instructions, scripts that download and run code, credentials and known-vulnerable packages. A model can read it too, with no tools.

Pick it, or let the agent choose.

Type $ in the prompt box or press Use on a skill. Its instructions go with that message, and the prompt box shows which skills are attached.

01What you can do · With skills
See every skill

Skills are grouped by folder. When two share a name, the card shows which one the agent loads.

Use it in a message

Press Use or type $. The skill goes with your next message, and its chip stays in the transcript.

Install from a link

A SKILL.md file, a GitHub folder or a .zip or .tar.gz. Choose this project or every project.

Edit it in place

Change SKILL.md on its page, or open its files in the editor. A save that breaks the skill is refused.

Keep it current

Check for updates fetches each skill installed from a link. You see a scan of the new version before it replaces the old one.

Copy, hide or remove

Copy a skill between the project and your global folder. Hide a built-in skill and restore it any time.

02Safety · Scanned before install

Read before it runs. Scanned before it lands.

Loading a skill runs nothing. A script in a skill runs only when the agent calls it through the shell, and that asks for approval like any command. Before an install or an update, KodaCode checks every file and shows what it found. When a finding is High, Install becomes Install anyway.

03For teams · Project skills

One set of steps, every agent on the team.

Skills in .koda/skills go with the repository. Commit them, and every teammate's agent follows the same release steps, migration rules and review checklist. A project skill overrides a global skill with the same name.
