Terminal

Your terminal, inside the workspace.

Stop switching windows to check the agent’s work.

Press ⌃` and a shell opens under the session, already inside the container your project runs in, in the project folder. Run the tests the agent just changed, curl the server it started or check git, then hide it and carry on where you were. Nothing to switch to, nothing to set up.

One window, not five.

The agent’s transcript, your files and your shell stay side by side. Dock the terminal under the session or float it over Koda; hide it and its tabs are still there when you come back.

Starts where your code runs.

For a project in Docker or Podman, the terminal opens inside its container, with the same files and tools the agent uses. A shell on your own machine is one click away.

Fewer windows. More focus.

01Why it’s built in

Fewer windows, less switching.

Checking an agent’s work usually means another terminal app, a cd into the right folder and remembering which container the project runs in. Koda’s terminal already knows: it opens in the project, in its container, next to the session you’re reviewing.

Same filesThe project folder, or the goal’s copy when you open it from a goal
Same toolsThe container image the agent’s commands run in, so a test you run matches the one it ran
Same projectEach project keeps its own terminals; switch projects and you see that project’s tabs
Same windowNo alt-tab, no lost place in the transcript
02What you can do
Container by default

A project that runs in Docker or Podman opens its terminal in that container. While the container starts, the terminal says so.

Your machine when you need it

New terminal offers a host shell too: your own shell, in the project folder, labelled HOST.

Look inside a goal

From a goal’s copy, open a shell in the goal’s container and see exactly what it is working on.

Docked or floating

Dock it under the session and drag its edge, or float it over Koda and move and resize it. Koda remembers which.

Your keys stay yours

Inside the terminal only the terminal toggle is captured, so Ctrl-R, Ctrl-C and the rest reach your shell.

Your theme

The terminal uses the colours and font of the theme you picked, and follows it when you change it.
