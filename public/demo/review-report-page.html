3. remaining underflows once a key passes its limit

self.limit - *hits is u32 subtraction: it panics in debug builds and wraps to about 4 billion in release once hits exceeds limit.

Triggered by

The first request over the limit: debug builds panic while holding the lock; release builds send X-RateLimit-Remaining: 4294967295.

Fix

Use saturating_sub.

Suggested fix (applies cleanly)
-            remaining: self.limit - *hits,
+            remaining: self.limit.saturating_sub(*hits),
