02Works without you

Four ways to hand off a task.

Work with the agent turn by turn, hand a task to a crew of cheaper models, let an automation watch on a schedule, or accept a plan, set an optional dollar budget and leave it running.

AgentsHand each job to the right agent.

Set up a reviewer, a test writer or a researcher, each with its own instructions and model. The lead decides who gets what.

See agents → CrewA frontier model leads, or none at all.

/crew-supervised: a leader plans, sets the check and judges each result. /crew-self-managed: one cheap or local model plans, codes and checks its own work.

See crew → AutomationsAutomate anything it can read.

Use any model to watch your infrastructure, network, builds or logs on a schedule. When something needs attention, it starts an agent.

See automations → GoalsPlan it and leave it.

Accept a plan, set an optional dollar budget, and the agent runs it in the background. Merge the result as one commit.

03Automations

Watch one get made.

This one checks a Kubernetes cluster named pharma every 15 minutes. A small model on your own machine reads its nodes and pods and decides whether the cluster is healthy. If it is, nothing happens. If it isn't, an agent starts, investigates and reports what it found. Six automations come built in, and you can add as many as you want.
