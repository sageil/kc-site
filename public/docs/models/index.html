Models & providers

Connect providers, choose the active model, and give agents, crews and automations their own.

Open Models & providers with /providers or from Preferences: "Where models come from: sign in, pick a default model, and choose the active one".

#Providers

ProviderSign-in

ChatGPTSign in with your ChatGPT account (device sign-in)
GitHub CopilotSign in with your GitHub account (device sign-in). KodaCode uses your Copilot plan.

Ollama CloudAPI key
CustomAny compatible endpoint, with a key

Add a provider picks an endpoint from the catalog or takes a URL.

  • Test Connection checks the provider.
  • Save & Set as Active makes it the active provider.
  • Remove provider deletes it.

KodaCode stores keys and sign-ins in your keyring.

The GitHub Copilot model list shows the models that your Copilot account turns on. Some of these models may not run on your plan. A request to such a model fails.

#Choose a model

/models or ⇧⌘L opens Choose a model. There you can:

  • pick a provider
  • Search models
  • filter to Only models with Tools, Reasoning or Vision
  • return to Use the default

The list shows recent choices first. The model picker in the top bar sets the model for the next message. Each project remembers its own model.

#A model per job

WhereSet it in
An agentIts Model field on the Agents screen
A review partThe review agent on the Agents screen
A crewLeader, worker, stronger and review models in Crew Workflow. Each workflow has its own worker model.
An automationIts decision model in the automation editor

#Reliability and cost

KodaCode retries a request that fails with a rate limit, overload, server error or dropped connection (3 attempts). If the provider is down, the turn then waits 15 to 60 seconds and tries again, up to 5 times. See General settings.

Anthropic models use a prompt cache, 5 minutes by default. Auto uses the 1-hour cache for sessions that you type into. /metrics shows what each provider cost.
