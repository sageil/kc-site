Keyboard shortcuts

Every keyboard shortcut in the KodaCode desktop app, with the keys for macOS and for Windows and Linux.

⌘ on macOS is Ctrl on Windows and Linux, ⌥ is Alt and ⇧ is Shift. /shortcuts (⇧⌘/) shows this list in the app.

#App

ActionmacOSWindows & Linux
New session⌘NCtrl+N
Command menu⌘KCtrl+K
Open a file⌘PCtrl+P
Sessions⌘OCtrl+O
Switch project⇧⌘OCtrl+Shift+O
Settings⌘,Ctrl+,
Keyboard shortcuts⇧⌘/Ctrl+Shift+/
Choose a model⇧⌘LCtrl+Shift+L

#Layout

ActionmacOSWindows & Linux
Larger text⌘=Ctrl+=
Smaller text⌘-Ctrl+-
Reset text size⌘0Ctrl+0
File panel⌘BCtrl+B
Inspector⌥⌘BCtrl+Alt+B
Terminal⌘J or ⌃`Ctrl+J or Ctrl+`
Prompt box⇧⌘JCtrl+Shift+J

#Screens

ActionmacOSWindows & Linux
Code graph⇧⌘GCtrl+Shift+G
Memory⇧⌘MCtrl+Shift+M
Agents⇧⌘ACtrl+Shift+A
Automations⇧⌘RCtrl+Shift+R
Autonomous tasks⇧⌘BCtrl+Shift+B
Logs⇧⌘ECtrl+Shift+E
Metrics⇧⌘UCtrl+Shift+U
Close the screenEscEsc

Esc closes a screen only when focus isn't in a field or a dialog.

#Agent

ActionmacOSWindows & Linux
Send, or steer a running turn↵Enter
Queue after the running turn⇧↵Shift+Enter
Stop the runEscEsc
Plan mode⇧⌘PCtrl+Shift+P
Focus the prompt box, or ask about the selection⌘LCtrl+L
Approve the change↵Enter
Reject the change⌫Backspace

In the / and @ lists:

  • ↑ ↓ move. In the command list, ← → also move.
  • Tab or ↵ picks.
  • Esc dismisses.

#Editor

ActionmacOSWindows & Linux
Save⌘SCtrl+S
Find⌘FCtrl+F
Replace⌥⌘FCtrl+Alt+F
Wrap long lines⌥ZAlt+Z
Comment the line⌘/Ctrl+/

⌘L isn't taken inside the editor. Inside the terminal, KodaCode captures only the terminal toggle, so the shell keeps its Ctrl keys.
