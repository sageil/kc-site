MCP servers

Tools, prompts and views from Model Context Protocol servers over stdio or HTTP, with OAuth sign-in and per-tool approvals.

KodaCode speaks MCP 2026-07-28 only. Add servers in Preferences → MCP servers. Your servers apply to every project. A project can add its own servers in .koda/mcp.toml.

#Add a server

Choose Add server:

Field
Name
TransportCommand (stdio) or URL (HTTP)
URLFor HTTP
HeadersOne Name: value per line. $secret keeps a value in the keychain.
Client IDOnly if the provider asks for one registered for KodaCode
Command, ArgumentsFor stdio. One argument per line.
EnvironmentOne NAME=value per line. $secret keeps a value in the keychain.
ApprovalDefault, Auto, Writes, Always or Never

For each server, you can Approve it, Sign in or Sign out (OAuth), Restart it, enable or disable it, edit it and remove it. A server in a project's .koda/mcp.toml starts only after you approve it. Changes apply from the next session.

#Approvals

ApprovalWhen it asks
AutoFor every tool, unless the server marks the tool read-only
WritesFor every tool that is not read-only
AlwaysFor every call
NeverNever

You set the default in Permissions & sandbox. A server's own approval wins over the default.

#What servers can do

  • Tools appear in the transcript as plug rows with the server's tool name.
  • Prompts appear in the / command list, marked mcp.
  • Views: a server's app view shows inline in the transcript, with Open in its own tab and Bring back here. Calls and links that a view requests need your approval.
  • Questions: a server can ask for input during a call ("Input requested by…"). You can answer, choose Give nothing so that it continues without the input, or choose Stop the whole call.
  • Background tasks: a long tool call can run as a task in Autonomous tasks. The agent waits for it with check_task or stops it with cancel_task.

#config.toml

[[mcp_server]]
name = "linear"
transport = "http"
url = "https://mcp.linear.app/mcp"
approval = "writes"

Other keys: enabled, command, args, env, cwd, headers, enabled_tools, disabled_tools, startup_timeout_secs (30), tool_timeout_secs (300) and client_id.
