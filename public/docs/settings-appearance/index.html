Docs/Settings

Appearance

How Koda looks, and how much of each run the transcript shows.

#Theme & text

Colours, spacing, text size and the code font.

#Theme

The colours of the app, code, the editor and the terminal.

#Density

Spacing between editor tabs, tree rows and diff lines.

#Interface text

The size of every label, message and list, and the spacing around them. Code keeps its own size below.

#Code font

The font and size for code, diffs, the editor and the terminal. Only monospaced fonts installed on this machine are listed.

#Transcript

What a run shows while it works.

#Tool calls

Compact draws the session as plain lines: one per call with its time, diffs under their edit, and your message and each answer between bars. Click a call to see its output. Live step keeps only the running call, and a failure in the latest turn, as cards. Grouped folds each run of quiet calls into one line.

#Show thinking

On, the model's thinking shows open beside its answer. Off, it folds into one line that you can click to read. Compact hides it.

#Turns shown

How many of the newest turns a session draws. Older turns load from a row at the top, so a long session stays quick.

#Motion

Decoration while a turn works. Each option plays here before it is chosen.

#Composer border

The border the composer wears while a turn is working, a compaction included.

#Working star

The star that plays while a turn is working, a compaction included.
