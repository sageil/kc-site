Docs/Settings

Settings overview

Every Preferences page, how settings are saved, and how projects override them.

Open Preferences with ⌘, or /settings. Search all settings finds any row. Each row has a reset link that returns it to its default. Reset to Defaults resets every setting on the screen. Projects, providers and directories stay. Open config file opens ~/.config/kc/config.toml, where KodaCode saves every setting. When you change a row marked Restarts containers, KodaCode restarts the running project containers.

#Projects override defaults

The Runs on chip beside the prompt box gives each saved project its own settings:

  • Sandbox.
  • Base image.
  • Approvals.
  • Review after every turn.
  • Parallel autonomous tasks.

A project's own choice wins over the defaults here. See Projects.

Each settings page below lists its rows word for word as the app shows them. Their defaults and config.toml keys follow.
