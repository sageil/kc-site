#Defaults and config keys

SettingDefaultconfig.toml
Review agents at once1 (1–4)[review] parts_at_once
Challenge threshold8 of 10[review] threshold
Challenge each finding separatelyTogether[review] challenge_each
Check suggested fixes againstHead commit (or Working tree)[review] patch_base = head_commit, working_tree
ScannersKoda's copies (or From PATH)[review] scanners = managed, path
Refresh the vulnerability database dailyDaily[review] refresh_daily

With Review agents at once at 1, the review's agents run one after another in a fixed order. So one review never sends your provider more than one request at a time. Scanners and advisories shows the scanners' versions and advisory freshness, with Refresh now. The review always checks uncommitted changes against the files on disk. See Code review.
