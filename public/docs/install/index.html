Docs/Getting started

Install

Get KodaCode on macOS, Windows or Linux, and know where it keeps its data.

Note KodaCode is coming soon for macOS, Windows and Linux. See Download for availability. It costs $10 a month after a 14-day free trial. You bring your own models and pay your providers directly.

#What you need

  • macOS, Windows or Linux.
  • An account with a model provider, or a local model through Ollama. See Models & providers.
  • git for goals, crews, review and rewind. A project that isn't a git repository still works for sessions. KodaCode can run git init for you when you add it.
  • Optional: Docker or Podman to run projects in a container (Isolation).
  • On Windows, Git for Windows: commands run in its Git Bash unless you choose another shell.

#Where KodaCode keeps its data

Everything KodaCode keeps for you lives in one folder, ~/.config/kc (or the folder named by the KODA_DATA_DIR environment variable):

PathWhat it holds
config.tomlEvery setting. Preferences → Open config file opens it.
transcript.dbYour sessions.
logs.dbWhat KodaCode logged, readable with /logs.
AGENTS.mdInstructions you give the agent in every project.
agents/Your global agents.
skills/Your skills.
automations/Your personal automations.
hooks.jsonHooks that run in every project.
themes/VS Code colour themes you add.

KodaCode never writes API keys, provider sign-ins or MCP secrets to these files. It keeps them in the system keychain: Keychain on macOS, Credential Manager on Windows, Secret Service on Linux.

Each project also gets a .koda/ folder for its own agents, skills, automations, rules and the copies KodaCode works in. See Files & folders.
