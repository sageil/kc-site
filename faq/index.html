Questions

Asked and answered.

01Questions
What is KodaCode?A desktop app for macOS, Windows and Linux that runs AI coding agents on your code. A lead agent hands work to agents you set up, scheduled checks call in an agent when something needs doing, and plans you agree on run in a separate copy of your project.
How much does it cost?$15 a month, or $144 a year, after a 14-day free trial. Every feature is included. You bring your own models and pay your providers directly.
Which models does it work with?Anthropic, ChatGPT, OpenAI, Google, DeepSeek, Qwen, OpenRouter, Ollama, or your own endpoint. You can give every agent on the crew a different model.
Can I use local models?Yes. Run models on your own machine through Ollama or your own endpoint, including the small decision models that automations use.
Where are my keys and sign-ins stored?In your system's keychain: Keychain on macOS, Credential Manager on Windows and Secret Service on Linux. That covers API keys, provider sign-ins, MCP server secrets and sign-ins, and your web search key. They're never written to a plain-text file or an environment variable, and never sent anywhere except the service they belong to.
Can the agent change files without asking?Only if you let it. For each project, choose whether changes ask before each one or apply directly, and whether commands that reach outside the project ask first. Every run can be undone in one click.
Can it run in a container?Yes. Each project can run in Docker or Podman, where the agent sees only the project and the folders you share, and your terminal opens in the same container.
Does it review code?Yes. /review checks your uncommitted work, a branch, a commit or the whole project for security, correctness, best practice and your own rules, with dependency and secret scanners, and lists the worst problems first.
Does it support MCP?Yes. Add MCP servers over stdio or HTTP, sign in with OAuth where a server needs it, and choose how often each tool asks before it runs.
When can I download it?Soon, for macOS, Windows and Linux.
