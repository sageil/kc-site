01What you can do · In the editor
Ask about a selection

Select any lines and click "Ask the agent about this selection". They're quoted into your message with the file and line numbers.

Review where it lands

A proposed edit opens in its file with the removed and added lines marked. Accept with ⌘↵, or reject with ⌘⌫ and a note the agent reads.

Never lose a review

A file with an edit waiting for you can't be closed by accident, and the tab is marked until you decide.

See what the agent is doing

The path bar tells you when the agent is reading or editing the file you have open.

A real editor

Syntax for Rust, TypeScript, JavaScript, Python, Go, Java, C, C++, SQL, HTML, CSS, JSON, YAML, Markdown and more. Search, folding, bracket matching and completion.

Keep your drafts

Unsaved changes stay with their tab while you switch files. ⌘S saves, and a terminal is a keystroke away.
